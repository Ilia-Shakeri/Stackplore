# Smart Assistant — راهنمای اپراتور پردازندهٔ محلی ویندوز

[English](local-processor.md) · [قرارداد پروفایل](local-profile.md) ·
[وضع اجرای رودمپ](implementation.md)

این ابزار برای اپراتور میزبان است؛ قابلیت محصول را فعال نکند و به‌تنهایی
پایان هیچ گام نباشد. نگه‌دارنده، نصب و شروع محلی را خواسته است. پذیرش اجرا،
رسید واقعی با منبع دقیق بخواهد. رد پیشینِ راه‌اندازی در بررسی خودکار، شکست
بماند. اگر اجرای تازه رد شد، همان نتیجه حفظ شود؛ روش اجرا عوض نشود.

PowerShell نسخهٔ **۷٫۴ یا تازه‌تر** و ویندوز لازم. اپراتور مورد اعتماد میزبان
اجرا کند؛ حساب محلی جدا بهتر. فهرست پردازش و رسید خصوصی، مسیر فایل را به
همان حساب نشان دهند. برنامه‌های دیگر همین میزبان نیز به loopback دسترسی
دارند؛ این مرز، جداسازی کاربران محلیِ نامطمئن نیست. پورت عمومی یا قانون
دیوارهٔ آتش افزوده نشود.

## فایل‌های مصوب

نصب آماده و تأییدشدهٔ CPU x64 لازم:

| مورد            | مقدار لازم                                                         |
| --------------- | ------------------------------------------------------------------ |
| انتشار          | `b11729`، فایل `llama-b11729-bin-win-cpu-x64.zip`                  |
| SHA-256 بایگانی | `aef737d26bffd08ceeb7be75f045bdef6d1ecc3187e0f4a1a3b0d878a03d2550` |
| منبع            | `412a363c655b479279d3050d0d1c67a5733697b4`                         |
| build پردازش    | `b11729-412a363c6`                                                 |
| پوشهٔ نصب       | دقیقاً ۵۱ فایلِ هم‌نام بایگانی؛ بی‌فایل اضافه و بی‌پیوند           |
| مدل             | یک فایل محلی `.gguf` با مسیر صریح و SHA-256 کاملِ جداگانه‌تأییدشده |

بایگانی از [انتشار رسمی ثابت](https://github.com/ggml-org/llama.cpp/releases/tag/b11729)
گرفته شود. دانلود خصوصیِ موجود به نام `llama-b11729-win-cpu-x64.zip` تغییر نام
یافته؛ بایت‌ها و hash لازم همان‌اند. ابزار، بایت را ببندد، نه نام بایگانی.
فایل مدل از ناشر مصوب، با نسخه و مجوز بررسی‌شده تهیه شود؛ hash
کامل آن جدا سنجیده شود. راه‌انداز، دانلود یا استخراج نکند و مدل انتخاب نکند.
نسخهٔ ۳ GGUF، شمار محدود سرآیند و اندازهٔ ۱۶ MiB تا ۸ GiB را بسنجد؛ این
بازه، تضمین RAM یا کیفیت نیست. alias دقیقاً `sha256-` و hash کوچکِ مدل است.

پروب دورریختنیِ نخست از `Qwen/Qwen3-0.6B-GGUF`، نسخهٔ
`23749fefcc72300e3a2ad315e1317431b06b590a`، مجوز Apache-2.0 و فایل
`Qwen3-0.6B-Q8_0.gguf` استفاده کند؛ **۶۳۹٬۴۴۶٬۶۸۸ بایت** و SHA-256:
`9465e63a22add5354d9bb4b99e90117043c7124007664907259bd16d043bb031`.
این فقط هویت ورودی تست است؛ کیفیت جواب آن پروفایل را قبول نکند.

مسیرها، خصوصی و کامل روی درایو محلی باشند؛ فقط اپراتور آن‌ها را بدهد.
مسیر شبکه، پیوند و reparse در والدها رد شوند. مرورگر مسیر ندهد. پیش از اجرا،
hash بایگانی، تک‌تک ۵۱ فایل نصب و خود مدل سنجیده شوند. دستگیرهٔ فقط‌خواندنی
تا پایان شروع باز بماند؛ جایگزینی هنگام سنجش و بارگذاری بسته شود. بعد از
بسته‌شدن دستگیره‌ها، پوشه و مدل همچنان زیر کنترل اپراتور بمانند.

## سنجش، شروع و توقف

از ریشهٔ مخزن اجرا شود. مسیرهای واقعیِ تأییدشده و hash کامل کوچک جایگزین
شوند. پوشهٔ خصوصی بیرون مخزن، با دسترسی محدود و از پیش موجود باشد.

```powershell
$privateRoot = 'D:\Stackplore-local-processor'
$inputs = @{
  Archive = Join-Path $privateRoot 'llama-b11729-win-cpu-x64.zip'
  RuntimeDirectory = Join-Path $privateRoot 'llama-b11729'
  Model = Join-Path $privateRoot 'approved-model.gguf'
  ModelSHA256 = '<independently-verified-64-character-lowercase-digest>'
}

# پیش‌فرض: فقط سنجش فایل؛ بی‌اجرای برنامه و بی‌درخواست شبکه.
& .\scripts\local-processor.ps1 @inputs

# شروع صریح؛ هر تلاش، رسید خصوصی تازه بخواهد.
$receipt = Join-Path $privateRoot ('processor-' + [guid]::NewGuid().ToString('N') + '.json')
& .\scripts\local-processor.ps1 @inputs -Action Start -ReceiptPath $receipt -Threads 2

# فقط پردازشِ بسته به همان رسید متوقف شود.
& .\scripts\local-processor.ps1 -Action Stop -ReceiptPath $receipt
```

`Start` هر listener موجود روی **۵۸۱۰۲** را رد کند؛ سپس فقط
`127.0.0.1:58102` را در پنجرهٔ پنهان آغاز کند. دو تا چهار رشتهٔ CPU، یک slot،
context برابر ۲۰٬۴۸۰، cache نوع `q8_0` و بی‌ offload.
origin مجاز مرورگر دقیقاً `http://127.0.0.1:58102` باشد؛ بازتاب پیش‌فرضِ origin
دلخواه بسته شود. پروب فقط برای میزبان مورد اعتماد است و اعتبارنامهٔ ورود
پیکربندی نکند.
مهلت شروع ۱۰ تا ۱۲۰ ثانیه، پیش‌فرض ۱۲۰. هر خواندن وضعیت، مهلت دو ثانیه و سقف یک MiB؛ redirect
و proxy محیط خاموش. PID صاحب listener پیش از درخواست سنجیده شود. پیش از
آماده اعلام‌شدن، مسیر و زمان پردازش، build، alias، hash قالب، context و slot
سنجیده شوند. شروع موفق، کیفیت جواب یا زمانِ بار کامل و سقف ۲۵ ثانیه‌ای محصول
را ثابت نکند.

فلگ‌های ثابت، رابط وب، اجرای ابزار داخلی، proxy رابط، endpoint مربوط به slot،
بارگیری خودکار مدل و projector، cache پرسش، جابه‌جایی context و ثبت متن خام
را خاموش کنند. فلگ ابزار، media، router، ذخیرهٔ slot و تغییر props داده نشود.
متغیرهای پردازنده، دانلود، proxy و اعتبارنامه از محیط فرزند حذف؛ محیط والد
دست‌نخورده. متن مدل به دستور پوسته تبدیل نشود. فلگ‌ها از
[مرجع رسمی همین منبع](https://github.com/ggml-org/llama.cpp/blob/412a363c655b479279d3050d0d1c67a5733697b4/tools/server/README.md)
گرفته شده‌اند. این تنظیم محدود است؛ sandbox سیستم‌عامل نیست.

رسید خصوصی، مسیر فایل، hash، PID، زمان UTC شروع، تنظیم و نتیجهٔ امن داشته
باشد؛ commit یا منتشر نشود. خروجی معمول فقط pin، شمار، تنظیم و کد ثابت خطا؛
مسیر مدل، پرسش، جواب و بدنهٔ خطای upstream ندهد. رسید عمومیِ کمینه و بسته به
منبع، تنها پس از اجرای تست واقعی ساخته شود.

`Stop` مسیر دقیق فایل اجرا، PID و زمان شروع را لازم دارد و hash همان فایل را
بسنجد. PID بیگانه یا دوباره‌مصرف‌شده رد شود. شکست شروع، رسید خود را حفظ کند؛
فقط پردازش با مالکیت اثبات‌شده متوقف شود. پوشه، مدل، بایگانی، رسید و پردازش
بی‌ربط حذف نشوند. رسید شکست دوباره به کار نرود؛ کد ثابت بررسی و تلاش مجاز
بعدی با رسید تازه انجام شود.

## تست و مرز گام

```powershell
pwsh -NoProfile -File .\scripts\local-processor.test.ps1
```

تست خالص، برنامه یا شبکه راه نیندازد. pin، سرآیند و سقف GGUF، نام فایل،
فلگ، پاک‌سازی محیط فرزند، نقل‌قول مسیر و مالکیت سنجیده شوند؛ این‌ها مدرک
نصب و شروع واقعی نیستند.

پس از شروع واقعیِ مجاز، تست دو زبانِ اختیاری در
[قرارداد پروفایل](local-profile.md#real-integration-gate) اجرا شود. منبع، hash
بایگانی/مدل/قالب، build واقعی، سخت‌افزار، شمار و مدت بسته شوند. اجرای محصول
تا پذیرش رزرو پایدار، سیاست مشترک، اختیار جاری و گیت‌های همان گام‌ها خاموش
بماند. این ابزار، انتخاب نشانی یا مسیر فایل را وارد API محصول نکند.
