# 1.0 requirement reconciliation at the 0.9.0 candidate

This matrix follows accepted ADRs and [SPEC.md](../../../SPEC.md). Implementation
and a passing fixture are separate claims. The final tag must still pass the
complete local, exact CI and artifact gates. Historical receipts are not
relabelled as proof of a later executable. The active evidence plan identifies
each final replacement run.
