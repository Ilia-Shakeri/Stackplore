# Stackplore

**تمام سرویس‌های پشتهٔ خود را کاوش کنید.**

[English](README.md)

> **وضعیت پروژه:** مرحلهٔ دو یک پوستهٔ مسیریابی‌شده و واکنش‌گرا، پوسته‌های روشن، تیره و هماهنگ با سامانه، قلم‌های محلی، دارایی‌های نشان تجاری جایگزین‌پذیر و اجزای رابط دسترس‌پذیر فراهم می‌کند. گردش‌کارهای محصول، ارائه‌دهندگان، ذخیره‌سازی، احراز هویت، بسته‌های استقرار، دمو و نسخهٔ منتشرشده هنوز وجود ندارند.

Stackplore یک کاوشگر زیرساخت خودمیزبان در دست طراحی است که برای شناخت محیط‌های Docker و Kubernetes از طریق یک رابط وب یکپارچه ساخته می‌شود. دامنهٔ نسخهٔ نخست شامل توپولوژی، سلامت، گزارش‌ها، معیارها، رویدادها، هشدارها و عملیات محدود و محافظت‌شده خواهد بود تا روند عیب‌یابی روشن و منسجمی فراهم شود.

## مسیر برنامه‌ریزی‌شده برای نسخهٔ نخست

- کشف منابع Docker،‏ Docker Compose و Kubernetes با یک مدل مشترک برای ارائه‌دهندگان
- توپولوژی زنده همراه با منشأ و میزان اطمینان هر رابطه
- منابع قابل جست‌وجو، جزئیات سلامت، گزارش‌ها، معیارها و تاریخچهٔ رویدادها
- قواعد هشدار محلی، اعلان‌های درون‌برنامه‌ای و اتصال‌های خروجی اختیاری
- حالت فقط‌خواندنی به‌صورت پیش‌فرض، مجوزدهی صریح و ثبت ممیزی برای تغییرهای مجاز
- حساب‌های محلی با نقش مدیر و مشاهده‌گر
- رابط کامل فارسی و انگلیسی با پشتیبانی درست از چیدمان راست‌به‌چپ و چپ‌به‌راست
- وب‌اپلیکیشن واکنش‌گرا و قابل نصب
- حالت دموی قطعی و قابل تکرار که از زیرساخت واقعی به‌روشنی جدا است
- استقرار خودمیزبان با کانتینر و Kubernetes

موارد بالا هدف‌های طراحی هستند و قابلیت‌های موجود مخزن را توصیف نمی‌کنند. تحویل پروژه به مرحله‌های بازبینی‌پذیر تقسیم شده است تا مستندات، پیاده‌سازی، آزمون‌ها و بسته‌های استقرار هماهنگ پیش بروند.

## وضعیت کنونی مخزن

مرحلهٔ صفر تعریف محصول، مرزهای معماری، مدل امنیتی، برنامهٔ تحویل و استانداردهای همکاری را پایه‌گذاری کرد. مرحلهٔ یک فضای کاری pnpm، داربست وب با TypeScript سخت‌گیرانه، داربست API با Go، آزمون‌ها، ساخت‌ها و ورودی‌های قابل‌حمل فرمان‌ها را اضافه کرد. مرحلهٔ دو سامانهٔ رابط مشترک، مدیریت پوسته، ناوبری واکنش‌گرا، پایهٔ مسیرها و دارایی‌های نشان تجاری محلی را اضافه می‌کند.

## توسعه

نسخه‌های دقیق Node.js،‏ Corepack،‏ pnpm و Go را مطابق [راهنمای توسعه](docs/development.md) آماده کنید و سپس فرمان‌های زیر را اجرا کنید:

```sh
node scripts/bootstrap.mjs
corepack pnpm run verify
corepack pnpm run dev
```

صفحهٔ توسعه در `http://127.0.0.1:5173` در دسترس است. API در این مرحله فقط به نشانی حلقهٔ محلی متصل می‌شود.

## رویکرد امنیتی

Stackplore برای دسترسی به زیرساخت حساس طراحی شده است. در طراحی برنامه، اطلاعات اتصال ارائه‌دهندگان فقط در سمت سرور می‌ماند، مقادیر محرمانه برای استنتاج جست‌وجو نمی‌شوند، فیلدهای حساس در مرز ارائه‌دهنده حذف می‌شوند و این مقادیر نگه‌داری، ثبت یا نمایش داده نمی‌شوند. دسترسی‌ها حداقلی هستند، رفتار پیش‌فرض فقط‌خواندنی است و هر عملیات مجاز به کنترل‌های صریح نیاز دارد.

اطلاعات ورود، توکن دسترسی، کلید خصوصی، محتوای kubeconfig، دادهٔ نشست، نشانی خصوصی زیرساخت یا گزارش‌های پاک‌سازی‌نشده را در درخواست‌ها و تغییرهای پیشنهادی قرار ندهید. روش گزارش خصوصی آسیب‌پذیری در [SECURITY.md](SECURITY.md) آمده است.
